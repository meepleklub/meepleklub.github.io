# Editing the Gallery

- Each immediate subdirectory is an album. The directory name is displayed as the album title.
- Copy event photos into the appropriate album directory.
- Create a new directory here for each new event.
- The image filename is used as its description. Use descriptive filenames.
- Supported formats: AVIF, GIF, JPG, JPEG, PNG, SVG, and WebP.

Example:

```text
src/assets/gallery/
├── 2026 holiday game day/
│   ├── group game.svg
│   └── group photo.jpg
└── Game nights/
    └── strategy game.webp
```
